# 0004. Чернетка заявки — AI SDK 7 + безкоштовні моделі OpenRouter

- Статус: прийнято
- Дата: 2026-11-05
- AC: AC-DRAFT-01, AC-DRAFT-02, AC-DRAFT-03, AC-DRAFT-04, AC-DRAFT-05, AC-DRAFT-06, AC-DRAFT-07

## Контекст

- PM (`requirements/03-request-draft-assistant.md`): працівник описує відсутність своїми словами, портал заповнює
  форму чернеткою; нічого не зберігається до «Подати заявку»; неоднозначне — «уточніть», не про відсутність —
  відмова; вказівки в тексті не виконуються; помічник недоступний — ручна форма працює. Якість — 10 golden cases,
  поріг PM 8/10.
- Бюджет курсу — нуль: у кожного в команді власний **безкоштовний** ключ OpenRouter (не спільний ключ курсу).
- Обмеження безкоштовного тарифу OpenRouter (docs/api/reference/limits, перевірено 04.11.2026): моделі з `:free` —
  20 запитів/хв; 50 запитів/день, якщо куплено менше 10 кредитів (1000/день — з 10); лічильник — за UTC-день
  (оновлюється о 02:00 за Києвом), залишок показує `GET /api/v1/key` → `data.free_model_daily_requests`.
  «Making additional accounts or API keys will not affect your rate limits» — додаткові ключі ліміт не множать.
- Безкоштовні моделі змінюються. 04.11.2026 у каталозі — 12 id з `:free`; `structured_outputs` (строгий JSON
  Schema) серед обраних має лише `nvidia/nemotron-3.5-super-vl:free`; обидві Gemma 4 `:free` мають лише
  `response_format`.
- Дані: безкоштовні провайдери можуть зберігати й тренуватися на запитах; чи обов'язковий перемикач приватності
  для безкоштовних моделей саме для цих моделей — **не перевірено** (без ключа не перевірити). Опис відсутності
  може містити подробиці про здоров'я.

## Рішення

1. **Бібліотеки (точні версії, без `^`)**: `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0` (peer `ai ^7`,
   `zod ^3.25.76 || ^4.1.8`), `zod@4.6.7`. API AI SDK 7: `generateText({ instructions, prompt, output:
   Output.object({ schema }) })` — `generateObject` і `system` у версії 7 позначені deprecated.
2. **Чиста функція** `extractDraft({ text, today }, model)` (`src/lib/request-draft/extract.ts`): модель — параметр,
   тому тести підставляють `MockLanguageModelV4` (`ai/test`) без мережі. Відповідь моделі — zod-схема
   `ModelDraftSchema` (`status: ok | needs_info | refused` + поля форми, «невідомо» = `null`); дати й заміну
   перевіряють ті самі функції, що й подання форми (`validateDates`, `normalizeSubstitute`). «Сьогодні» —
   параметр (за Києвом), не `new Date()` усередині.
3. **Модель**: `openrouter.chat(chain[0], { models: chain })` — серверний fallback OpenRouter по ланцюжку
   `google/gemma-4-31b-it:free → google/gemma-4-26b-a4b-it:free → nvidia/nemotron-3.5-super-vl:free`
   (`src/lib/request-draft/models.ts`). `OPENROUTER_MODEL` ставиться першою лише якщо закінчується на `:free`:
   платна модель у `models` тарифікується за платною ціною. `provider.require_parameters` не вмикаємо (Gemma без
   `structured_outputs` випала б з маршрутизації) — тому схема продубльована в промпті, а zod перевіряє завжди;
   JSON у ```` ```json ```` розбираємо самі.
4. **Ключ лише на сервері**: `src/lib/request-draft/openrouter.ts` — перший рядок `import "server-only"`, єдине
   місце, що читає `OPENROUTER_API_KEY`; ключа немає → `null` → «Помічник зараз недоступний» (AC-DRAFT-06).
   Клієнтський компонент імпортує лише `@/lib/request-draft/state`. Правило перевіряє `npm run check:boundary`.
   `npm run build` і `npm test` ключа не потребують.
5. **Ліміти й збої**: `maxRetries: 0` (за замовчуванням AI SDK — 2; повтор після 429 лише палить ту саму денну
   квоту), `timeout` 25 с (`maxDuration` сторінки — 60 с). 429 (і HTTP 200 з `code: 429` у тілі), тайм-аут,
   нерозбірна відповідь, помилка провайдера → один стан «недоступний», форма лишається ручною.
6. **Prompt injection (AC-DRAFT-05)**: опис — лише між `<employee_text>…</employee_text>`, теги з тексту
   вирізаємо, довжина ≤ 500; інструкції кажуть, що це дані. Головний захист — не промпт, а архітектура: модель
   лише повертає поля форми (без tools), нічого не пише в базу, заявку створює людина своєю дією.
7. **Перевірка якості**: офлайн-реплей golden cases у `npm test` (CI) + живий `npm run eval` (окремий конфіг,
   ніколи в CI): послідовно, пауза 4 с, preflight квоти, модель для кожного case, pass rate проти порогу PM.
   Порівняння точне, без LLM-судді: усі поля перелічувані.

## Розглянуті варіанти

- **Спільний платний ключ курсу** — гроші й один лічильник на всіх; обіцянку платного ключа з WS6 скасовано.
- **Кілька безкоштовних акаунтів на людину, щоб обійти 50/день** — документація OpenRouter прямо каже, що
  ліміт це не змінює; і це не той приклад, який ми показуємо.
- **`generateObject`** — deprecated в AI SDK 7.
- **Строгий JSON Schema для всіх моделей (`require_parameters`)** — лишилась би одна модель з трьох.
- **Модель з tools («створи заявку сама»)** — суперечить AC-DRAFT-02 і відкриває ін'єкції з дією; не потрібно.
- **LLM-суддя для eval** — зайві запити з тієї самої денної квоти; поля перелічувані.
- **ZDR-ендпойнт (`xingchen-agi/xing4.0-29b-a4b:free`)** — єдиний безкоштовний ZDR, але лише en/zh.

## Наслідки

- Ціна — нуль, але 50 запитів/день на акаунт: 10 golden cases = 10 запитів; кілька прогонів eval і демо в один
  день можуть вичерпати ліміт. Тому `maxRetries: 0`, preflight у eval і стан «недоступний» у UI.
- Безкоштовні моделі зникають без попередження — перед заняттям і перед здачею перевірити `FREE_MODELS`
  (RUNBOOK-ws10) і перезаписати відповіді (`RECORD=1 npm run eval`).
- Якість на українській мові не гарантована: офлайн-тести перевіряють код навколо моделі, а не модель. Живий
  прогін 09.11.2026 дав pass rate 10/10, але всі відповіді — від `nvidia/nemotron-3.5-super-vl:free`; якість Gemma 4
  не виміряна (`docs/qa/eval/2026-11-09.md`). `tests/fixtures/golden/recorded.json` — записи з цього прогону.
- Дані: лише синтетичні описи в демо й тестах; підказка в UI — не вказувати діагноз; сервер логує лише результат
  і модель, без тексту опису. Для справжніх даних знадобиться платна модель з політикою без тренування або ZDR —
  окреме рішення.
- Vercel: без `OPENROUTER_API_KEY` у змінних проєкту задеплоєний портал показує «Помічник зараз недоступний», а
  форма працює вручну. Якщо ключ додати — це ключ одного акаунта, і його 50 запитів/день ділять усі, хто відкриває
  прод; у Preview — лише за рішенням команди (preview-збірка виконує код будь-якої гілки, як у ADR 0003).
- Заміна провайдера — один файл `models.ts`: `extractDraft` приймає будь-яку `LanguageModel` AI SDK.
